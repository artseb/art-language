# Standard Library

ART's standard library currently contains modules for common functionality.

## Math

The math library currently exposes values and functions including `pi`, `sqrt`, `pow`, `abs`, `floor`, `ceil`, `round`, `min`, and `max`.

## Strings

String utilities include operations for changing case, trimming, searching, replacing, splitting, joining, taking substrings, and getting length.

## Vector Types

The repository also contains `Vector2` and `Vector3` ART modules used as examples of user-defined mathematical types and operator overloading.

The standard library is expected to grow as ART develops.
