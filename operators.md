# Operators

ART provides arithmetic, comparison, logical, assignment, and other operators.

Common operators include:

```text
+  -  *  /  ^
== !=
<  <=  >  >=
and or !
=
```

## Operator Overloading

User-defined classes can provide implementations for supported operators.

This allows types such as vectors and other mathematical structures to define natural operations.

Operator dispatch and overload selection are handled by the runtime.
