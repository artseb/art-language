# Tables

Tables are ART's general-purpose collection value. They support indexed entries and key-value entries.

## Arrays

```art
numbers = [10, 20, 30]
```

ART tables use one-based indexing for array-style entries.

## Key-Value Tables

```art
player = {
    name = "Seb",
    health = 100
}
```

Tables can also contain mixed forms of data.
