# Language Overview

ART is a dynamically typed language with variables, functions, tables, classes, inheritance, interfaces, enums, modules, operator overloading, and structured control flow.

## Values

ART currently works with values including numbers, strings, booleans, nil, tables, functions, classes, and instances.

## General Syntax

Blocks use braces:

```art
if (condition) {
    print("yes")
}
```

Statements may be written without requiring a declaration keyword for ordinary variables.

## Comments

Single-line comments begin with `//`.

## Main Features

- Dynamically typed values
- Global variables by default
- Explicit local variables with `local`
- Multiple assignment/declaration
- Functions and lambdas
- Function overloading
- Classes, inheritance, interfaces, and static members
- Getters and setters
- Nested classes
- Tables
- Enums
- Operator overloading
- `if`, `while`, `for`, and `switch`
- `break` and `continue`
- Imports and modules
- Built-in and standard-library functions
